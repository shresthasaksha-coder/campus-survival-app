# Run the project on your Mac

1. Unzip this folder and open campus-survival-app in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install` and wait for it to finish.
4. Run `npm run dev`.
5. Open the Local URL printed in the terminal (usually http://localhost:5173).
6. Use the Housing or Dining links in Home navigation.

Requires Node.js 22 or later. If npm is not found, install Node.js first.

For a built version: `npm run build`, then `npm start`, then open http://localhost:3001.
For tests: `npm test`.

Read docs/HOUSING_DINING_HANDOFF.md for your demo and GitHub instructions.
